# sakana-widget-react Contributing Guide

## Setup

Use the Node.js version specified in `.node-version`.

Install dependencies with the repo-managed [pnpm](https://pnpm.io/)

```
pnpm install
```

### Run development environment(Storybook)

```
pnpm run dev
```

### Check and fix format and lint

```
pnpm run fmt
pnpm run lint:fix
```
